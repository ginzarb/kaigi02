# ぎんざRuby会議02

Ginza.rb 主催の地域Ruby会議「ぎんざRuby会議02」の告知サイトです。
HTMLとCSSのみで構成しており、ビルドは不要です。

## ローカルでの表示

`index.html`をブラウザーで開くか、リポジトリのルートで次のコマンドを実行し、
<http://localhost:8000>にアクセスしてください。

```sh
python3 -m http.server 8000
```

## デザイン素材

- イラストとGinza.rbのロゴは、[ぎんざRuby会議01](https://ginzarb.github.io/kaigi01/)の素材を使用しています。
  イラスト: [@ken1flan](https://github.com/ken1flan)。元ファイルは[前回のリポジトリ](https://github.com/ginzarb/kaigi01/tree/develop/source/images)にあります。
- タイトルの日本語書体は[Kaisei Decol](https://github.com/google/fonts/tree/main/ofl/kaiseidecol)（700）です。
  Google Fontsで「ぎんざRuby会議02」の文字だけにサブセット化したファイルを同梱しています。
  タイトルの文字を変える場合は、必要に応じてフォントのサブセットも更新してください。
  ライセンスは[assets/fonts/OFL.txt](assets/fonts/OFL.txt)を参照してください。
